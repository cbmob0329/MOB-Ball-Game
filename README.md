# KoKoRoの写真館 - GitHub Pages Deluxe v4

## 必須画像
GitHubリポジトリの `index.html` と同じ階層に、以下を置いてください。

- `back.png` … 背景画像
- `icon.png` … KoKoRoロゴ

## 今回の追加
- back.png を背景として導入
- icon.png をロゴとして導入
- ロゴを何個でも複数表示
- ロゴ一覧から選択
- 選択ロゴを1個削除
- ロゴを全削除
- 各ロゴごとに表示/非表示・移動・サイズ・透明度・ロック
- 背景の back.png / パターン / その他背景を切り替え可能

## GitHub Pages
`index.html`, `.nojekyll`, `back.png`, `icon.png` をリポジトリ直下へ置いてください。
