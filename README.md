# KoKoRoの写真館 - GitHub Pages Deluxe

## 公開方法
1. GitHubで新しいリポジトリを作成
2. このフォルダの `index.html` と `.nojekyll` をリポジトリ直下へアップロード
3. `Settings` → `Pages` → `Deploy from a branch`
4. Branch: `main` / Folder: `/(root)`
5. 保存後、`https://ユーザー名.github.io/リポジトリ名/` で公開
